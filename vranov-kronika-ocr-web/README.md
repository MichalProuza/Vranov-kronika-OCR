# Kronika obce Vranov – OCR web, prvních 5 stran

Samostatný webový výstup pro prvních pět nejstarších stran sekce **Úvod až rok 1919** z obecní kroniky na webu obce Vranov.

## Soubory

- `index.html` – statický web s obrázky originálů, strojově čitelným textem a vyhledáváním.
- `data.json` – stejný přepis ve strukturované podobě pro další zpracování.

## Poznámka k OCR

První čtyři strany jsou převážně titulní nebo krátké záznamy. Pátá strana je hustý rukopis; nejasné části jsou označené jako `[?nejisté?]` a nepřečtené úseky jako `[nečitelné]`.
