# Kronika obce Vranov — rok 1962 (rozpracovaný přepis)

Z osmi skenů jsou zatím přepsány pouze vybrané čitelné úseky. Hranaté závorky označují chybějící nebo nejistý text. Tento dokument není úplným ani souvislým přepisem roku.

Zdroj: https://www.vranov.cz/obec/historie/kronika-obce-vranov/rok-1960-1964-8cs.html
