# Kronika obce Vranov — rok 1960 (rozpracovaný přepis)

Z patnácti skenů jsou zatím přepsány pouze vybrané čitelné úseky. Hranaté závorky označují popis obsahu, chybějící nebo nejistý text. Tento dokument není úplným ani souvislým přepisem roku.

Zdroj: https://www.vranov.cz/obec/historie/kronika-obce-vranov/rok-1960-1964-8cs.html
