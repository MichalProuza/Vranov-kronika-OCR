# Galerie 1955–1959 — roky 1955–1959

Zdroj: https://www.vranov.cz/obec/historie/kronika-obce-vranov/rok-1955-1959-7cs.html

Rok 1955 zahrnuje skeny 1–19 (ID 318–336, strany 79–97); strany 79–85 mají pracovní přepis, ostatní strany zatím chybí. Rok 1956 zahrnuje skeny 20–47 (ID 337–364, strany 98–125); všechny strany mají pracovní záznam. Rok 1957 zahrnuje skeny 48–76 (ID 365–393, strany 126–154), rok 1958 skeny 77–98 (ID 394–415, strany 155–176) a rok 1959 skeny 99–130 (ID 416–447, strany 177–208). Přepisy let 1956–1959 jsou neúplné.
