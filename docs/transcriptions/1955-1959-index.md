# Galerie 1955–1959 — roky 1957–1959

Zdroj: https://www.vranov.cz/obec/historie/kronika-obce-vranov/rok-1955-1959-7cs.html

Rok 1957 zahrnuje skeny 48–76 (ID 365–393, strany 126–154); prvních deset stran má rozpracovaný přepis. Rok 1958 zahrnuje skeny 77–98 (ID 394–415, strany 155–176) a rok 1959 skeny 99–130 (ID 416–447, strany 177–208). Přepisy let 1958–1959 jsou rovněž neúplné.
