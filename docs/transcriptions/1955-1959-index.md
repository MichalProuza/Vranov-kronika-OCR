# Galerie 1955–1959 — roky 1958–1959

Zdroj: https://www.vranov.cz/obec/historie/kronika-obce-vranov/rok-1955-1959-7cs.html

Rok 1958 začíná na skenu 77/130 (ID 394, strana 155) a končí na skenu 98/130 (ID 415, strana 176). Rok 1959 následuje na skenech 99–130 (ID 416–447, strany 177–208). U obou let je přepis zatím rozpracovaný; u roku 1958 jde hlavně o orientační popis obsahu.
